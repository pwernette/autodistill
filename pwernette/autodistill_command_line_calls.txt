## ANNOTATION MODE ##
# This uses YOLOE to automatically segment grapes and generate YOLO-format labels with train/val split:
python grapefinder_image_ann_train.py \
    -annotate /mnt/d/sfm_greeen_2025harvest/20250926_oxley/for_annotation \
    -outdir /mnt/d/sfm_greeen_2025harvest/GrapeFinder_yoloe_yolo11_segmentation \
	-yoloe_model m \
    -device cuda \
	-conf 0.25 \
    -val_split 0.2 \
    -iou_thresh 0.5 \
    -min_area 0.001 \
    -max_area 0.8
	
-annotate: folder containing your raw grape images
-outdir: where the YOLO dataset will be saved
-device cuda: use GPU if available
-conf: confidence threshold
-val_split: fraction of images reserved for validation (default 0.2)
-iou_thresh: NMS IoU threshold for filtering overlapping detections
-min_area / --max_area: area thresholds for objects

This produces:
	images/ and labels/ folders
	data.yaml for YOLO11 training



## TRAINING MODE ##
# This trains YOLO11 on the dataset generated in Annotation mode
python grapefinder_image_ann_train.py \
    --train \
    --outdir path/to/output_dataset \
    --epochs 50 \
    --device cuda \
    --weights path/to/pretrained_yolo11.pt   # optional, can be omitted to start from scratch

--train: triggers YOLO11 training
--outdir: same folder as step 1 (data.yaml is read from here)
--epochs: number of training epochs
--weights: optional, use a pretrained YOLO11 checkpoint

After training, the best weights are stored in runs/train/grape_yolo11_seg/weights/best.pt.



## INFERENCE MODE ##
# This runs sliced inference on a single image or a folder of images using the trained YOLO11 model:
python grapefinder_image_ann_train.py \
    --infer path/to/test_image_or_folder \
    --infer_weights runs/train/grape_yolo11_seg/weights/best.pt \
    --device cuda

--infer: single image path or folder of images
--infer_weights: path to YOLO11 weights
--device: use GPU (cuda) or CPU (cpu)

Each image will run through SAHI sliced inference, and predictions will be printed.
